# Duo 부고알림 KBoard 관리자 사용 가이드

이 문서는 Duo 부고알림 KBoard 스킨을 처음 사용하는 관리자를 위한 운영 안내서입니다.

## 1. 이 게시판으로 할 수 있는 일

Duo 부고알림은 워드프레스 KBoard 기반 부고 게시판입니다. 관리자는 부고를 등록하고, 방문자는 목록과 상세 페이지에서 부고 정보를 확인할 수 있습니다.

주요 기능은 다음과 같습니다.

- 부고 등록, 수정, 삭제
- 고인 사진 등록
- 소속, 고인명, 상주명, 별세일, 입관일, 발인일, 장례식장, 장지 관리
- 목록과 모바일 목록 자동 표시
- 최신글 위젯 표시
- 최신글 5건 초과 시 자동 롤링
- 고인명, 상주명, 날짜, 소속, 장례식장, 장지 통합 검색
- 지난 부고 자동 구분
- CSV 내보내기

## 2. 설치 전 준비

먼저 워드프레스에 KBoard 플러그인이 설치되어 있어야 합니다.

필수 조건:

- WordPress 5.0 이상
- KBoard 플러그인 활성화
- 관리자 권한 계정

## 3. 플러그인 설치

1. 워드프레스 관리자에 로그인합니다.
2. `플러그인 > 새로 추가 > 플러그인 업로드`로 이동합니다.
3. `duo-obituary-kboard.zip` 파일을 업로드합니다.
4. 설치 후 `활성화`를 누릅니다.

KBoard가 비활성화되어 있으면 관리자 화면에 안내 문구가 표시됩니다. 이 경우 KBoard를 먼저 설치하고 활성화하세요.

## 4. 게시판 만들기

1. 워드프레스 관리자에서 `KBoard > 게시판 목록`으로 이동합니다.
2. 새 게시판을 만들거나 기존 게시판을 선택합니다.
3. 게시판 기본설정에서 스킨을 `Duo 부고알림`으로 선택합니다.
4. 게시판 설정을 저장합니다.
5. 생성된 게시판 숏코드를 원하는 페이지에 넣습니다.

일반 게시판 예시:

```text
[kboard id="1"]
```

`id` 값은 실제 게시판 ID로 바꿔야 합니다.

## 5. 부고 등록 방법

1. 부고 게시판 페이지로 이동합니다.
2. 관리자 권한으로 접속하면 목록 하단에 `부고 등록` 버튼이 표시됩니다.
3. `부고 등록`을 누릅니다.
4. 입력 항목을 작성합니다.
5. `저장`을 누릅니다.

입력 항목:

- 사진: 고인 사진 이미지
- 소속: 부서, 단체, 호실 등 관리자가 쓰는 구분값
- 고인명: 필수
- 상주명: 필수
- 별세일
- 입관일
- 발인일: 필수
- 장례식장
- 장지
- 비밀번호: 비회원 작성 또는 KBoard 설정에 따라 사용

제목은 관리자가 직접 입력하지 않아도 됩니다. 저장 시 `소속/고인명/별세일` 조합으로 자동 생성됩니다.

## 6. 목록 화면 이해하기

목록에는 다음 정보가 표시됩니다.

- 소속
- 고인명
- 상주명
- 별세일
- 입관일
- 발인일
- 장례식장
- 장지

고인명을 누르면 상세 페이지로 이동합니다.

지난 부고는 회색 배경과 `지난 부고` 배지로 구분됩니다. 지난 부고 기준은 발인일이 현재 날짜보다 이전인 경우입니다.

## 7. 검색 사용 방법

목록 상단 검색창에 검색어를 입력하고 `검색`을 누릅니다.

검색 대상:

- 소속
- 고인명
- 상주명
- 별세일
- 입관일
- 발인일
- 장례식장
- 장지

예를 들어 장례식장 이름, 장지, 상주명 일부만 입력해도 해당 부고가 검색됩니다.

## 8. 최신글 위젯 사용

메인 페이지나 별도 영역에 최신 부고 위젯을 표시하려면 KBoard 최신글 숏코드를 사용합니다.

예시:

```text
[kboard_latest id="1" url="/obituary" rpp="100"]
```

설정값:

- `id`: 부고 게시판 ID
- `url`: 부고 게시판 페이지 주소
- `rpp`: 가져올 최대 글 수. 롤링 안정성을 위해 `100`을 권장합니다.

최신글 위젯 동작:

- 발인일 기준 최신 부고를 표시합니다.
- 지난 부고는 최신글 위젯에서 제외됩니다.
- 표시 항목이 5개를 초과하면 자동 롤링됩니다.
- 표시 항목이 5개 이하이면 롤링하지 않고 그대로 보여줍니다.
- 검색 중에는 롤링이 멈추며, 결과가 잘리지 않도록 높이가 자동으로 조정됩니다.

## 9. CSV 내보내기

KBoard 게시판 관리 화면의 `확장설정` 탭에서 `Duo 부고알림 Export` 패널을 사용할 수 있습니다.

내보내기 기능:

- 최근 게시글 미리보기
- 원하는 게시글 선택 내보내기
- 전체 내보내기
- 작성일 기준 기간 필터
- 내보낼 컬럼 선택

CSV에 포함 가능한 컬럼:

- 게시글 ID
- 작성일
- 상태
- 소속
- 고인명
- 상주명
- 별세일
- 입관일
- 발인일
- 장례식장
- 장지
- 제목

엑셀에서 열 수 있도록 CSV 파일로 다운로드됩니다.

## 10. 운영 팁

- 발인일은 최신글 표시와 지난 부고 구분에 사용되므로 반드시 정확히 입력하세요.
- 검색이 잘 되려면 소속, 장례식장, 장지 같은 보조 정보도 가능한 한 일관된 이름으로 입력하세요.
- 최신글 숏코드의 `url`은 반드시 실제 부고 게시판 페이지 주소로 설정하세요.
- 모바일에서는 최신글이 간단한 표 형태로 표시됩니다.
- 항목이 길어 줄바꿈이 생겨도 최신글 영역은 롤링하지 않는 상황에서 내용을 잘라내지 않습니다.

## 11. 문제 해결

### 스킨이 보이지 않습니다

KBoard가 활성화되어 있는지 확인하세요. 그 다음 게시판 기본설정에서 스킨을 `Duo 부고알림`으로 다시 선택하고 저장합니다.

### 검색 결과가 이상합니다

검색어가 소속, 고인명, 상주명, 날짜, 장례식장, 장지 중 하나에 포함되어 있는지 확인하세요. 검색은 게시판 목록과 최신글 표시 모두에 적용됩니다.

### 최신글이 롤링하지 않습니다

표시되는 부고가 5개 이하이면 롤링하지 않는 것이 정상입니다. 5개를 초과하면 자동 롤링됩니다.

### 지난 부고가 최신글에 보이지 않습니다

정상 동작입니다. 최신글 위젯은 현재 또는 예정 부고만 보여줍니다. 일반 목록에서는 지난 부고도 확인할 수 있습니다.
