# Duo 부고알림 KBoard 스킨

KBoard 본체를 수정하지 않고 별도 WordPress 플러그인으로 설치하는 부고알림 전용 KBoard 스킨입니다.

## 구조

- `skin/duo-obituary-kboard/`: 개발 원본 스킨
- `plugins/duo-obituary-kboard/`: WordPress 플러그인 패키지
- `scripts/build-plugin.sh`: 원본 스킨을 플러그인 패키지에 복사하고 zip 생성
- `dist/duo-obituary-kboard.zip`: WordPress 업로드 설치용 zip

## 설치

1. `scripts/build-plugin.sh`를 실행합니다.
2. WordPress 관리자에서 `dist/duo-obituary-kboard.zip`을 업로드해 설치합니다.
3. KBoard 플러그인을 활성화합니다.
4. KBoard 게시판 스킨에서 `Duo 부고알림`을 선택합니다.

KBoard가 비활성화되어 있으면 이 플러그인은 관리자 알림만 표시하고 스킨 등록은 하지 않습니다.

## 점검

설치 패키지와 핵심 동작은 아래 명령으로 점검합니다.

```bash
./tests/smoke.sh
```

점검 항목은 플러그인 로드, KBoard 비활성 상태 알림, 스킨 등록, PHP 문법 검사, 빌드 스크립트, zip 무결성, zip 필수 파일 포함, 지난 부고 판단, 제목 자동 생성, 저장값 백업/복구, 공개/관리자 목록 쿼리 정책입니다.

## 최신글 쇼트코드

```text
[kboard_latest id="게시판ID" url="https://example.com/obituary/" rpp="10" mobile_rpp="5"]
```

`url`에는 부고 리스트가 있는 페이지 주소를 넣어야 합니다.

## 필드 정책

- 소속: 선택
- 고인명: 필수
- 상주명: 필수
- 별세일: 선택
- 입관일: 선택
- 발인일: 필수
- 장소: 선택
- 장지: 선택
- 사진: 선택

KBoard 기본 제목은 화면에 입력받지 않고 `소속/고인명/별세일` 형식으로 자동 생성됩니다. 빈 값은 제외됩니다.

## 샘플 데이터

관리자가 `Duo 부고알림` 스킨이 적용된 게시판을 처음 열면 테스트용 부고 10건이 자동 생성됩니다. 같은 게시판에는 한 번만 생성됩니다.

## 노출 정책

- 기본 정렬은 발인일 임박순입니다.
- 일반 사용자는 발인일 다음날 00:00부터 지난 부고를 목록, 검색, 최신글에서 볼 수 없습니다.
- KBoard 관리권한 사용자는 지난 부고도 볼 수 있으며, 지난 부고는 목록 뒤쪽에 회색 톤과 배지로 표시됩니다.
- 지난 부고의 상세 URL 직접 접근은 허용됩니다.

## 화면 정책

- 데스크톱 최신글: 소속, 고인명, 상주명, 별세일, 장소
- 데스크톱 리스트: 소속, 고인명, 상주명, 별세일, 입관일, 발인일, 장소, 장지
- 모바일 최신글/리스트: 고인명, 상주명, 소속, 발인일, 장소 중심의 리스트형 항목
- 상세: 사진과 소속, 고인명, 상주명, 입관일, 발인일, 장소, 장지 표
