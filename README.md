# Duo Obituary KBoard Skin

KBoard 전용 부고 알림 스킨입니다. 현대적인 디자인과 고성능 무한 롤링 위젯을 제공합니다.

## ✨ 주요 기능
- **심리스 무한 롤링**: Web Animations API 기반의 끊김 없는 수직 롤링
- **스마트 검색**: 상주명/고인명 실시간 검색 및 자동 멈춤 기능
- **반응형 디자인**: 데스크탑/모바일 최적화 레이아웃 (고정 헤더)
- **자동 관리**: 발인일이 지난 부고 자동 필터링 기능
- **현대적 UI**: 부드러운 그림자와 품격 있는 색상 조합

## 📂 디렉토리 구조
- `plugins/duo-obituary-kboard`: 워드프레스 플러그인 소스코드
- `dist/`: 설치용 배포 파일 (.zip)
- `USER_GUIDE.md`: 사용자 및 관리자를 위한 매뉴얼

## 🚀 설치 방법
1. `dist/duo-obituary-kboard.zip` 파일을 다운로드합니다.
2. 워드프레스 관리자 페이지 > 플러그인 > 새로 추가 > 플러그인 업로드에서 설치합니다.
3. 활성화 후 KBoard 게시판 설정에서 `Duo 부고알림` 스킨을 선택하세요.
